# Job Application Automation Pipeline

A Make.com pipeline that screens job applications in batches and triages applicants into a Google Sheet.

## How it works

Google Docs (applications) -> Make AI Toolkit (analysis and scoring) -> Make AI Web Search (enrichment) -> Google Sheets (triage results)

- Runs **on demand** or on a **15-minute schedule**
- Useful for batch job screening, applicant triage and content analysis

## Stack

Make.com, Make AI Toolkit, Make AI Web Search, Google Docs, Google Sheets
